Understanding the Simulation

Bernoulli Process

Each request fails independently with fixed probability. Like flipping a biased coin - no memory of previous flips. Models random, uncorrelated outages.

ARTA Process

Failures are autocorrelated - if one request fails, the next is more likely to fail too. Models real-world cascading failures: network outages, rate limiting, service degradation.

Harmful ESCAPED

Harmful requests NOT caught by the guardrail - these reach the user. Lower is better.

Safety Rate

Percentage of harmful inputs blocked: blocked / harmful × 100. Higher is better.

Max Failure Burst

Longest consecutive sequence of LLM failures. During a burst, ALL requests use the weak naive fallback. ARTA produces longer bursts than Bernoulli.
